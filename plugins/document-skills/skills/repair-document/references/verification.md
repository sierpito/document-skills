# Verification

Static analysis alone reports a clean file that collides on screen. Each check below targets a
regression that repairs commonly cause. All output goes to the working folder.

| Check                                                                           | Command or method                                                                                                                                                                                                                   | Typical failure it catches                                      |
|---------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------|
| Schema and package validation                                                   | the pptx skill's `validate.py <out> --original <input>` (read-only, no `--auto-repair`)                                                                                                                                             | A paragraph split that produced mismatched `<a:r>`/`<a:p>` tags |
| Package audit (fallback when `validate.py` is missing, and always alongside it) | every part has a content type; every `Target` resolves; every `r:id` is declared; no unreferenced media                                                                                                                             | A label removal that left two of three references behind        |
| Render and look                                                                 | `soffice --headless --norestore --convert-to pdf --outdir render/ out/<name>`, then `pdftoppm -png`, then read the images                                                                                                           | A heading overlapping its own bullet list                       |
| Pairwise overlap test                                                           | compare every text box with every other for more than 0.05in overlap in both axes                                                                                                                                                   | Entry titles wrapping into the row beneath                      |
| Off-canvas and margin test                                                      | right edge vs slide width, bottom vs height                                                                                                                                                                                         | A footer whose second line ran off the bottom                   |
| Font resolution                                                                 | `pdffonts render/<name>.pdf`                                                                                                                                                                                                        | Bold actually resolves - a serif and a serif-bold both appear   |
| Image presence                                                                  | `pdfimages -list render/<name>.pdf`                                                                                                                                                                                                 | All images survived the `p:pic` conversion                      |
| Previewer visibility                                                            | every image is a `p:pic` with a resolving internal PNG/JPEG target; render with LibreOffice and, if present, `qlmanage -t -s 1600 -o render/ out/<name>` (macOS Quick Look); compare `pdfimages -list` count with the `p:pic` count | An image group no previewer drew                                |
| No wrapping or overflow                                                         | for each text box, rendered line count equals source line count (`pdftotext -bbox-layout`), no box text past its box edge, no `normAutofit` shrink hiding overflow                                                                  | A title wrapping onto its subtitle                              |
| Render fidelity                                                                 | `pdftotext -raw`, normalise punctuation, assert every source line appears                                                                                                                                                           | Known false positive: an underlined run merges its space        |
| Content diff against input                                                      | compare text and notes string by string; hash every media part                                                                                                                                                                      | Images byte-identical; only intended strings changed            |

A previewer that does not answer is a lead, not a verdict. Run Quick Look (`qlmanage -t`) or LibreOffice with a
timeout of 60-120 s. No thumbnail on a heavy deck (many freeform picture fills, SVG icons, several-MB images) means
"investigate image size and count", not "pass" and not "proven defect": say which it was, with the time you waited.

Two habits matter more than any single check:

- **Re-render after every repair group**, because fixing the font changes what collides.
- **Diff against the input every time.** Your own edits are the likeliest source of new defects, and a
  diff is the only thing that separates "I fixed it" from "I changed something and did not notice".
