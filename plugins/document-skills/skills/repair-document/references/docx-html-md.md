# DOCX, HTML, Markdown and plain text (PDF: `detect-pdf.md`)

## DOCX

Shares the `docProps` checks with PPTX. What differs:

- **No revision save ids.** Real Word writes `w:rsid` values that accumulate across sessions; a
  generated file has none, or one uniform value. Nothing to repair - report it.
- **Direct formatting instead of styles.** Every run carries explicit `<w:rPr>` and `styles.xml` goes
  unused. Repair by mapping repeated direct formatting onto real styles; it also makes the document
  editable.
- **Literal bullets** (U+2022 or `-`) at the start of paragraphs instead of `numbering.xml` lists. Same
  fix as PPTX, under the glyph-cleanup input.
- **Default-font tells.** Aptos in a file claiming to predate 2023; Calibri 11 everywhere.
- **No `w:lastModifiedBy`, no `w:proofState`, zero comments, zero tracked changes** in a document that
  claims several revisions. Report.

## HTML

The signals are mostly in what is missing:

- `<meta name="generator">`, or a `<!-- Generated by ... -->` comment. Remove or correct.
- Everything inline, no stylesheet, no favicon, no `lang`, no meaningful `<title>`. Real defects; fix.
- Class names like `section-1`, `container-wrapper-inner`, or none at all. Report.
- Identical structural rhythm: every section an `<h2>` plus exactly three `<p>`. Report.
- Inline `style=` on every element where a stylesheet belongs. Fix if prose_edits allows structure work.

## Markdown and plain text

Structure before prose:

- Heading-per-paragraph scaffolding; a bold lead-in on every bullet. Report.
- Numbered lists that are always exactly three items. Report.
- Mixed straight and curly quotes in one file; non-breaking spaces (U+00A0). Report; normalise only if
  the user agreed.
- **Zero-width characters** (U+200B, U+200C, U+200D, U+FEFF). Invisible, survive copy-paste, and the
  one text-level marker that can be deliberate. Removed by default under glyph cleanup, except where
  RTL or legitimate joining needs them.
- Conversational residue: an opening "Certainly! Here's...", a closing "Let me know if you'd like me
  to...", a sign-off addressed to nobody. Safe to remove - it was addressed to a chat window, not the
  reader - and counted as "rewritten" in the ledger.
